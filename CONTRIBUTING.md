# Contributing

1. Create a feature branch from `main`.
2. Keep model weights, generated images, private profiles, and credentials out of Git.
3. Run `ruff check .` and `pytest -q` before opening a pull request.
4. Add unit tests for command, policy, workflow, and response-shape changes.
5. Keep the default public demo suitable for a general audience.

Use conventional commit prefixes where practical: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.
