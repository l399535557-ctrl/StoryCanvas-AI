# 后端验收清单

本文用于冻结毕业设计后端范围。清单完成后，新增开发只针对独立 Web 前端；新模型、复杂
向量检索、分布式队列和论文级算法优化均不属于当前毕设必做范围。

## 1. 自动化验收

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
```

通过标准：测试全部通过，Ruff 无错误，GitHub Actions 对相同命令验证成功。

## 2. 数据层验收

1. 运行 `storycanvas-seed-demo` 创建演示存档。
2. 在 `/docs` 中确认存档包含两轮历史和三条记忆。
3. 检查每条记忆的标签、重要度和来源轮次。
4. 使用关键词检索，确认结果只来自当前存档。
5. 归档一条记忆，确认其不再进入正常列表和 RAG；随后恢复。
6. 导出存档并以新 ID 导入，确认原存档未被覆盖。

## 3. 生成链路验收

1. 启动 ComfyUI 和网关，确认 `/health` 中 `comfyui_ok=true`。
2. 使用普通消息完成一次文本续写。
3. 使用 `/图` 完成一次强制插图。
4. 查看故事历史，确认回复、图片任务、任务状态和图片文件相互关联。
5. 导出 publication ZIP，确认 Markdown 中插图位于对应故事轮次下。
6. 使用流式请求，确认响应以 `[DONE]` 结束。

## 4. 恢复能力验收

1. 创建数据库备份并记下存档和记忆数量。
2. 新增一条测试记忆，再恢复备份。
3. 确认新增数据被回滚，并生成恢复前安全快照。
4. 让一个图像任务失败或取消，然后执行重试。
5. 在任务运行时关闭服务并重新启动，确认遗留任务被标记为失败。

## 5. 异常与隐私验收

1. 关闭 ComfyUI，确认健康状态降级且管理接口仍可用。
2. 使用错误网关密钥，确认受保护接口返回 401。
3. 使用错误文本模型配置，确认返回可理解的 502 错误。
4. 访问非法图片路径，确认返回 404。
5. 检查日志和诊断响应，确认不包含密钥、正文、记忆正文和内部图像提示词。
6. 检查 Git 跟踪文件，确认没有 `.env`、数据库、备份、模型或生成图片。

## 6. 答辩材料

建议保留以下证据：系统架构图、数据库关系图、Swagger 接口截图、RAG 检索结果、任务状态
截图、备份恢复记录、测试通过截图、作品 ZIP 和完整演示视频。

通过以上清单即可认定后端达到毕业设计演示要求。真机模型测试属于部署验收活动，不再扩展
新的后端功能；剩余实现范围仅为独立 Web 前端。
