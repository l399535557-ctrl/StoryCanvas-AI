# StoryCanvas AI Web

StoryCanvas AI 的独立前端。默认中文、深色界面，同一套页面适配 PC、平板与手机。用户输入行动或决策，后端生成剧情和插图。保持 v0.13.0 后端行为：整轮文本与可选插图都完成后才返回，不宣称文字提前到达。

本分支只修改 `web/`，不修改 Python 后端、数据库、ComfyUI、Windows 启动脚本或生产部署。基线提交：`baf2353a0d2c60dc4b281d5186c4c9b5a460f2f9`。

## 本地运行

使用 Node.js 24 LTS（也支持 Node.js 22.12 及以上的 22 系列）。项目锁定依赖，跨平台使用同一份 `package-lock.json`。

```sh
cd web
npm ci
npm run dev
```

打开终端打印的 Local 地址。无需后端即可浏览首页和公开示例。

- 首页：`/#/`
- 只读示例：`/#/demo/chat`
- 真实网关设置：`/#/app/settings`

页面使用 hash 路由，刷新子页面不需要服务器重写到 `index.html`。系统使用本机字体，不依赖在线字体服务。

## 连接 Windows 网关

1. Windows 启动已有 FastAPI 和 ComfyUI。
2. 两台设备使用可信局域网或 Tailscale，确认 Mac 可以访问网关。
3. 复制 `web/.env.example` 为 `web/.env.local`，设置开发代理地址，例如：

```dotenv
VITE_DEV_PROXY_TARGET=https://your-windows-device.your-tailnet.ts.net
VITE_ASSET_BASE=/
```

4. 重启 `npm run dev`。页面的“服务地址”留空，使用同源开发代理。
5. 在页面填写独立的 `GATEWAY_API_KEY`。前端验证 `/health` 和 `/v1/models`，随后进入工作台。

Vite 代理 `/v1`、`/health` 和 `/images`，不会改写公开 API。生成请求的代理超时为十分钟，客户端整轮超时为十二分钟。

页面也支持直接填写 HTTP(S) 网关根地址，但此方式需要后端部署方设置允许的浏览器跨域来源，HTTPS 页面也不能直接调用 HTTP 网关。默认推荐同源代理；本分支不添加 CORS 或任何后端配置接口。

## 功能范围

- 项目首页、只读示例故事、示例记忆、插图放大与画廊。
- 对话默认 SSE，兼容普通 JSON 回复；技术选项从输入区收起，指令从“更多发送选项 → 指令帮助”进入。
- 每次对话显式携带 `story_save_id`；历史按正确顺序组装成近期上下文，去掉插图 URL 与耗时附注，并以字符预算限制历史长度。
- 本轮配图、网关共享自动配图指令、等待提示、失败时保留输入。
- 存档创建、选择、重命名、归档、恢复、复制、JSON 导入导出、图文作品 ZIP 导出。
- 历史、记忆、任务分页。正常刷新保留已经加载的旧历史。
- 记忆新增、修改、归档、恢复、冲突标记、激活、事实修订和来源编号。
- 插图按历史 `image_tasks` 关联，任务按 `request_id` 追踪；不使用时间戳猜测对应关系。
- 排队、运行、成功、失败、取消状态；处理中每三秒查询状态，支持取消和失败/取消任务重试。
- 健康检查、认证诊断、数据库备份列表、备份创建与整库恢复。
- 危险操作明确提示；整库恢复必须输入完整备份文件名确认。
- 主导航以故事列表为中心；记忆、插图和任务从“故事信息”进入，系统管理从“设置 → 高级与帮助”进入。
- 手机导航抽屉、管理表单、原图弹窗和输入区适配，支持软键盘改变可视高度。
- 中性灰深色界面、系统无衬线字体与少量香槟色强调；首页和管理文案使用简短说明，公开示例不展示修改按钮；保留原有圆角星芒品牌图标。

### 已知后端行为

- 自动插图开关为网关共享状态，不是每个存档独立设置。
- SSE 是整轮完成后的兼容分块输出，没有实时文本阶段或采样进度。
- 插图失败可能导致本轮 502 且文本尚未入库。客户端保留行动；不会自动重新发送，避免重复生成。
- 取消插图任务不等于停止文字生成。客户端不把关闭页面或断开 HTTP 连接当成取消任务。
- 旧的 `/记忆` 与 `/记忆状态` 命令依赖后端活动存档；前端发送这些命令前先用 `/存档 <当前 ID>` 对齐状态。日常记忆管理直接使用显式存档 API。
- 归档目标若仍是后端活动存档，确认后先切换到当前选中的另一个存档；后端默认存档仍受后端规则保护。
- 参数和上游模型密钥继续由后端 `.env` 配置。本前端没有虚构模型参数修改接口。
- 存档 JSON 是数据迁移格式，不包含实际图片文件；图文作品打包使用 publication ZIP。
- 来自旧历史的 `/images/*.webp` 地址（包括 Windows localhost 地址）通过当前网关/代理访问。
- API 返回的历史编号是数据库轮次 ID，任务页与来源追踪保留该编号。

## 示例与隐私

示例数据位于 `src/lib/demo.ts`，为公开展示专门编排，部分设定参考后端 `demo_data.py`；并非用户聊天记录，也不表示实时模型输出。插图来自仓库已有 `docs/assets/storycanvas-demo.webp`，复制为前端公开资产。

示例不调用真实网关。示例模式不提供新增、编辑、归档、导出、备份、任务取消与重试操作。进入连接设置并成功验证后才使用真实服务。

- 网关密钥只保存在 `sessionStorage`，关闭标签页通常清除；浏览器恢复会话可能保留，可主动断开连接。
- `localStorage` 只存网关地址和选中的存档 ID。
- 行动草稿和回复只在内存中保留，不存入浏览器长期存储。
- 不打印 Authorization、密钥、故事正文和记忆正文。
- Markdown 不渲染原始 HTML，链接只允许 HTTP(S) 与安全的相对地址。
- `.env.local`、`node_modules/`、`dist/`、覆盖率和编译缓存已通过 `web/.gitignore` 排除。
- 发布静态前端时不得把网关密钥放入 `VITE_*` 环境变量；它们会进入公开构建产物。

## 检查与构建

```sh
npm run lint
npm run test
npm run build
```

构建输出 `web/dist/`，不会提交到 Git。`npm run preview` 仅用于本地检查构建，不是生产服务器。

自动化测试覆盖：分块 UTF-8/CRLF SSE、`[DONE]`、中断与格式异常、鉴权与请求编号、导入复制返回字段、上下文顺序和预算、旧图片地址、示例模式不请求后端、移动导航与图片弹窗、连接、存档隔离、生成失败保留输入、记忆修改以及整库恢复确认。

## 交回 Windows

```powershell
git fetch origin
git switch frontend/mac-ui
git pull --ff-only
cd web
npm ci
npm run lint
npm run test
npm run build
```

Windows 负责审核分支并整合至最新 `main`，运行 Python pytest/Ruff，将 `web/dist` 接入静态服务或统一反向代理，然后完成真实 LLM、ComfyUI、SQLite 与前端的端到端验收。

如果页面部署在 `/ui/`，构建前设置 `VITE_ASSET_BASE=/ui/`；公开项目路径可设置 `/StoryCanvas-AI/`。开发代理只在 Vite 开发服务中有效，生产必须由 Windows 配置 `/v1`、`/health`、`/images` 的真实服务接入。

生产发布前需实机确认：普通文字、强制/自动配图、SSE、中文命令、历史刷新、存档隔离、失败取消重试、导入导出、备份恢复，以及真实手机浏览器和 Tailscale 图片访问。本 Mac 分支不把模拟接口测试计作真机验收。
