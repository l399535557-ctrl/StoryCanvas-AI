## 验证边界

本机没有使用 Windows 的真实 LLM、ComfyUI 或私有 SQLite。自动化接口测试使用按现有 Python 接口整理的测试响应，不能替代真实端到端测试。

初版及减法改版的浏览器截图接口持续返回 CDP 超时，因此未完成截图视觉验收。DOM 尺寸、语义和交互检查不等同于逐张截图视觉复核；请在 Windows 和真实手机浏览器查看最终外观、软键盘行为与图片尺寸。

## Windows 必须完成

1. 从 `frontend/mac-ui` 接回，在现有 Python 环境执行 pytest/Ruff。
2. 运行 `npm ci`、lint、test、build；通过开发代理或同源生产代理连接真实网关。
3. 验证文字、强制/自动配图、完整轮次 SSE、取消/失败重试，以及重试完成后历史图片刷新。
4. 验证两个真实存档的上下文、记忆与插图隔离，复制、导入导出和图文作品 ZIP。
5. 使用测试数据库验证备份创建和整库恢复，不在未备份的正式数据上做恢复演练。
6. 真实 PC/手机检查导航、弹窗、长正文、输入法、软键盘、图片加载失败和 Tailscale 访问。
7. 审核并整合至 main；由 Windows 配置静态托管和公开访问。Mac 分支未执行生产发布。
